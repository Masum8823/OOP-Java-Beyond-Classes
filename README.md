## About This Repository

This repository is specially designed for students who want to revise Java OOP quickly before:
- Exams
- Viva
- Lab Tests
- Interviews

All topics are written in simple `.md` format using easy English and smart-note style explanations so concepts become easy to remember after one quick reading.
